# 🗺️ Clothes App — Roadmap v6 (Solid Base First)

> Goal: stop adding features until the foundation is **correct, consistent, and trustworthy**.
> Each phase must be *fully green* (builds, lints, runs, no known bugs) before the next begins.

---

## Guiding principles

1. **Correctness before features.** A working small app beats a broken big one.
2. **One way to do each thing.** One Firebase SDK, one navigation pattern, one styling approach.
3. **Make CLAUDE.md true.** Either the code matches the stated stack, or the doc changes to match reality.
4. **Every phase ships green.** `lint` + `typecheck` + manual smoke test pass before moving on.
